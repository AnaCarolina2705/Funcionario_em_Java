# Funcionario_em_Java
Este projeto, feito com a linguagem Java, tem a função de cadastrar funcionários
e calcular seu salário líquido. 
O código utiliza conceitos de POO (programação orientada a objetos),
fazendo uso de herança, construtores, encapsulamento, entre outros. O programa permite
informar registro, salário base, cargo, quantidade de faltas, e, ao final, exibe o resultado 
calculado do salário líquido considerando as faltas e o desconto de 20%.
